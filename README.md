# 🎬 Movie Collection App – Interactive Movie Search Web Application

An advanced and responsive **Movie Collection Web Application** developed using **HTML, CSS, and JavaScript** with powerful **OMDb API Integration** for fetching real-time movie data.

This application allows users to create accounts, log in securely, and search for movies dynamically using movie titles. The project fetches live movie information from the OMDb API and displays details such as:

- Movie Posters
- Movie Titles
- Release Year
- Movie Type
- Search Results

The project demonstrates practical frontend development skills including:

- OMDb API Integration
- Fetch API handling
- Authentication workflow
- Dynamic DOM manipulation
- Real-time search functionality
- Responsive UI design
- LocalStorage management
- Interactive user experience

This project is designed to simulate a real-world movie browsing platform while improving JavaScript problem-solving and frontend application development skills.
